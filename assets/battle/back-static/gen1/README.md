# Generation 1 static back sprites

Source reference: [Pokémon Yellow Super Game Boy back sprites — Bulbagarden Archives](https://archives.bulbagarden.net/wiki/Category:Yellow_back_sprites_(Super_Game_Boy))

```powershell
python tools/import_yellow_sgb_back_sprites.py --root .
```

The importer writes the first 151 source PNGs here. Artwork is ignored by Git
and is not covered by the mod's MIT license. Verify that you have the right to
use and distribute it.
